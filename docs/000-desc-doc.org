* Description

By now Scala is obviously a well-known and well-understood programming language (both from a language-concept and from tools/tooling point of view).

And equally obvious the language and the user are moving on and these days more and more Scala3 becomes the Scala version of choice.

With that we are switching the focus of the meetup from Scala2 to Scala3.
